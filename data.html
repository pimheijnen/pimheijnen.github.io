Data and Code

Data

You can find the Dutch retail gasoline prices 2005-2011 here: https://easy.dans.knaw.nl/ui/datasets/id/easy-dataset:65108 (just register and you can download and use them for your own research). Disclaimer: no Edgeworth cycles or asymmetric price adjustment is present in this data!

Code

ComputeMixedNash: a Python package that numerically computes mixed-strategy Nash equilibria in discontinuous games, such as models of price competition: https://github.com/pimheijnen/ComputeMixedNash. The method is described in the paper On the Computation of Equilibrium in Discontinuous Economic Games (see Research).

ResEcon: a Python package that computes the optimal extraction of a renewable resource, such as a fishery or a lake, by value function iteration. It handles non-convex problems with tipping points and multiple steady states, and simulates and plots the optimal paths: https://github.com/pimheijnen/ResEcon.
